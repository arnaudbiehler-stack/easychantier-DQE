IA (Anthropic)
La clé API Anthropic est configurée une seule fois côté serveur (variable d'environnement) — elle n'est plus saisie ici et n'est jamais visible dans le navigateur.
Espace de travail partagé
Toutes les données (clients, lots, métrés) sont stockées sur le serveur et synchronisées automatiquement entre vous et vos collègues ayant le mot de passe de l'espace de travail (~4 secondes de délai). Pour changer de mot de passe, utilisez le bouton "⇅ Partager".

Espace de travail Easy Chantier

Demandez ce mot de passe à la personne qui a déployé l'outil (défini dans les paramètres du projet Vercel).

Partager avec un collègue

Toutes les données sont déjà partagées et synchronisées automatiquement entre toutes les personnes qui ouvrent cette même adresse avec le mot de passe de l'espace de travail — il n'y a rien à faire de plus. Donnez-leur simplement l'adresse du site et le mot de passe.
⚠ L'import remplace entièrement les données actuelles de l'espace de travail (tous les clients), pour tout le monde. Exportez d'abord une sauvegarde si vous ne voulez rien perdre.
